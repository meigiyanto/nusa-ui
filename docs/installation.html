Installation

Set up the framework in a new or existing project.

Requirements

  • Node.js 18+
  • npm 9+ (or pnpm / yarn)
  • Tailwind CSS v3.x (not v4)

1. Install dependencies

terminal 
npm install -D tailwindcss@3 postcss autoprefixer
npx tailwindcss init -p

2. Configure Tailwind

Point content at your HTML/JS files and enable class-based dark mode.

tailwind.config.js 
module.exports = {
  content: ["./src/**/*.{html,js}", "./public/**/*.html"],
  darkMode: "class",
  theme: {
    extend: {
      // See the full config in the repository
    },
  },
  plugins: [],
};

3. Add the CSS entry

Create your main CSS file and import the framework layers (or copy src/css/themes.css and the other partials).

src/css/tailwind.css 
@tailwind base;
@tailwind components;
@tailwind utilities;

@import "./themes.css";
@import "./base.css";
@import "./components.css";
@import "./utilities.css";

4. Build

terminal 
npx tailwindcss -i ./src/css/tailwind.css -o ./dist/css/framework.css --watch
# Production:
npx tailwindcss -i ./src/css/tailwind.css -o ./dist/css/framework.css --minify

5. Use components

Open any file under src/components/, copy the HTML, and paste it into your page. Interactive components need the corresponding JS module from src/js/components/.

CDN option (prototyping only)

For quick demos you can use the Tailwind CDN + our themes.css. For production, always use the built CSS so unused classes are purged.
