Theming

Customize colors, fonts, radii, and shadows without rewriting components.

How it works

Design tokens live as CSS custom properties in src/css/themes.css. Tailwind is configured to read those variables, so utility classes like bg-primary-600 stay in sync with your theme.

Light & Dark

Dark mode uses the .dark class on <html>.

JavaScript 
import { setTheme, toggleTheme, initTheme } from './src/js/core.js';

initTheme();          // respects localStorage + system preference
setTheme('dark');     // force dark
toggleTheme();        // flip light ↔ dark

Changing primary color

Override the primary scale in :root (and optionally in .dark):

CSS 
:root {
  --color-primary-500: #0ea5e9;
  --color-primary-600: #0284c7;
  --color-primary-700: #0369a1;
  /* …other steps as needed */
}

Custom theme

You can also scope tokens under a data attribute:

HTML + CSS 
<html data-theme="ocean">…</html>

[data-theme="ocean"] {
  --color-primary-500: #06b6d4;
  --color-primary-600: #0891b2;
}

Other tokens

  • --font-sans, --font-display — font families
  • --radius-sm … --radius-3xl — border radius
  • --shadow-sm … --shadow-2xl — elevation
  • --color-surface, --color-border, --color-text — surfaces & text
