Nusa UI Documentation

A reusable, responsive and customizable component framework for modern web applications.

Framework

Tailwind 3

Approach

Mobile First

Version

1.1.0

ℹ
Nusa UI provides reusable semantic CSS classes built on top of Tailwind CSS 3.

Installation

Install dependencies and compile the framework.

Terminal 
npm install
npm run dev

# Production build
npm run build

The compiled stylesheet is generated at dist/nusa-ui.css.

Basic Usage

Include the compiled CSS and optional JavaScript helpers in your HTML document.

HTML Setup 
<link rel="stylesheet" href="/dist/nusa-ui.css">
<script src="/src/js/nusa-ui.js" defer></script>
