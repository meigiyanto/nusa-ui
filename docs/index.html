Introduction

A complete, modern, responsive UI framework built on Tailwind CSS v3. Copy-paste friendly components, accessible interactions, and a consistent design system.

What you get

  • ✓ Design tokens (colors, radii, shadows, typography)
  • ✓ Core components: Buttons, Forms, Cards, Badges, Alerts
  • ✓ Advanced: Modal, Drawer, Tabs, Accordion, Dropdown, Toast, Tooltip
  • ✓ Marketing sections: Hero, Features, Pricing, Testimonials, CTA
  • ✓ Auth & Error pages
  • ✓ Light / Dark theme system
  • ✓ Vanilla JS interactions (no heavy dependencies)

Philosophy

  • Component-first — each component can be used independently.
  • Copy-paste friendly — take the HTML + Tailwind classes and drop them into any project.
  • Mobile-first — every component is designed for small screens first.
  • Accessible — semantic HTML, ARIA, keyboard support, focus management.
  • Themeable — change colors, radii, and fonts via CSS variables without rewriting components.
