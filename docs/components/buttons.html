Accessibility

  • Use <button type="button"> for actions that are not form submits.
  • Icon-only buttons must have an accessible name via aria-label.
  • Disabled buttons use the native disabled attribute.
  • Focus styles use focus-visible so keyboard users see a clear ring.

Full markup variants are available in src/components/buttons/button.html.
